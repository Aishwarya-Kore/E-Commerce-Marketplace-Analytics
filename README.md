# E-Commerce-Marketplace-Analytics

This project analyzes e-commerce data to understand sales performance, customer behavior, product categories, payment patterns, customer reviews, and delivery performance using PostgreSQL, SQL, Power BI, and DAX.

## 🎯 Business Objective

The objective of this project is to analyze e-commerce performance and identify business trends and areas for improvement.

The analysis focuses on:

- Sales and order trends
- Customer purchasing behavior
- Product category performance
- Payment method analysis
- Customer review patterns
- Delivery performance and delays

## 🗂️ Dataset & Data Grain

The project uses the Olist Brazilian E-Commerce Public Dataset available on Kaggle.

The dataset contains related information about orders, customers, products, sellers, payments, reviews, and deliveries.

The data was organized into analytical structures to support business analysis at appropriate levels of detail, including order, product, payment, and review levels.

## Key findings
- **R$13.59M revenue, 98.67K orders, 95.42K customers, AOV R$137.75.**
- **93.23% of delivered orders arrive on time** (6,534 late orders).
- **Late orders average a 2.27 review score vs 4.29 for on-time orders.**
- Top categories: health_beauty, watches_gifts, bed_bath_table. SP generates the most revenue by a wide margin.
- Jan-Aug 2018 revenue was about 137% higher than Jan-Aug 2017 (R$7.39M vs R$3.11M).
